🏛️ FMAuction
Современный, высокооптимизированный плагин на двухвалютный аукцион для серверов Minecraft

📖 О проекте
FMAuction - это гибкая и производительная система 
аукциона с открытым исходным кодом, поддерживающая 
одновременную работу двух независимых 
торговых площадок: обычной (игровая валюта) и донатной (рубли/поинты). 
Плагин разработан с упором на максимальную оптимизацию под высокие нагрузки и полную визуальную кастомизацию.

⚡ Производительность
В ходе нагрузочных тестов (активные покупки, спам кнопкой обновления меню, частые запросы к базе данных) плагин показал минимальное влияние на тикрейт сервера: https://spark.lucko.me/NtyZ1vuqJR

⚙️ Требования и зависимости
Для корректной работы плагина необходимы:
Ядро сервера: Paper, Purpur, Leaf и другие форки 1.20 – 1.21+
Версия Java: Java 21 или выше
Обязательные зависимости: Vault (и любой плагин на экономику)
Опциональные зависимости:
PlayerPoints — для работы донатного аукциона
PlaceholderAPI — для отображения статистики и топов

📦 Установка
Скачайте последнюю версию FMAuction.jar со страницы Releases.
Поместите скачанный файл в папку plugins/ вашего сервера.
Убедитесь, что установлены Vault, PlayerPoints и PlaceholderAPI.
Перезапустите сервер, чтобы сгенерировались файлы конфигурации.
Настройте config.yml под нужды вашего проекта и выполните /fmauction reload.


Основные команды:
/ah - Открыть главное меню монетного аукциона
/dah - Открыть главное меню донвтного аукциона
/dah sell {price} - Выставить предмет из руки на рублёвый аукцион
/ah sell {price} Выставить предмет из руки на монетный аукцион
/ah search {запросЪ - Найти предметы по названию на монетном аукционе
/dah search {запросЪ - Найти предметы по названию на рублёвом аукционе
/ah <игрок / магазин> - Показать лоты указанного игрока или магазина (монетный)
/dauc <игрок / магазин> - Показать лоты указанного игрока или магазина (донатный)
/fmauction reload - Перезагрузить плагин (fmauction.admin)

fmauction.update - возможность просмотреть обновления.
